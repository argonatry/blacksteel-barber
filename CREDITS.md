# Credits — медіа, шрифти, бібліотеки

Усі фото та відео взяті з бібліотек, що дозволяють **комерційне використання без зазначення авторства**. Список нижче — для прозорості та на випадок перевірки.

- **Unsplash License** — https://unsplash.com/license — безкоштовне використання, зокрема комерційне, без дозволу й атрибуції. Не можна продавати фото без змін та збирати з них конкурентний сервіс.
- **Mixkit Stock Video Free License** — https://mixkit.co/license/#videoFree — безкоштовно для комерційних і особистих проєктів, без атрибуції. Не можна перепродавати чи поширювати кліпи як окремі стокові файли.

Ліцензію кожного файлу перевірено на сторінці джерела 1 листопада 2026 року. Для фото — лише безкоштовні (не Unsplash+). Для відео — лише кліпи з позначкою `videoFree`, без `Restricted`.

## Обробка

Усі фото обрізано, переведено у WebP і приведено до єдиного тону (менша насиченість, теплий баланс, глибші тіні). Відео змонтовано у дві петлі по ~12 с (16:9 для десктопа, 9:16 для мобільного), затемнено й перекодовано в H.264.

Кадри з кліпів, де помітні чужі логотипи (принт на накидці, емблема на фартусі), у сайт не потрапили.
