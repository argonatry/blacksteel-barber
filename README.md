# BLACKSTEEL Barber Club

Односторінковий сайт барбершопу — демо-проєкт для портфоліо. Бренд, майстри й відгуки вигадані.

**Стек:** чистий HTML + CSS + JavaScript (ES-модулі), без збирачів. Анімації — GSAP + ScrollTrigger, плавний скрол — Lenis (обидва з CDN).

## Як відкрити локально

Сайт використовує ES-модулі, тому просто відкрити `index.html` подвійним кліком **не вийде**: браузер блокує модулі з `file://`. Потрібен будь-який локальний сервер. Варіанти на вибір:

**Python** (найпростіше, зазвичай уже встановлено):

```bash
python -m http.server 8000
```

**Node.js:**

```bash
npx serve .
```

**VS Code:** встановіть розширення *Live Server* → правий клік по `index.html` → *Open with Live Server*.

Після запуску відкрийте у браузері `http://localhost:8000` (або адресу, яку покаже команда).

## Як опублікувати на GitHub Pages

1. Створіть новий репозиторій на [github.com/new](https://github.com/new), наприклад `blacksteel-barber`. Тип — **Public**, без README.

2. У папці проєкту ініціалізуйте git і зробіть перший коміт:

   ```bash
   git init
   ```

   ```bash
   git add .
   ```

   ```bash
   git commit -m "BLACKSTEEL barbershop site"
   ```

3. Підключіть репозиторій і відправте код (замініть `USERNAME` на свій логін):

   ```bash
   git branch -M main
   ```

   ```bash
   git remote add origin https://github.com/USERNAME/blacksteel-barber.git
   ```

   ```bash
   git push -u origin main
   ```

4. На GitHub відкрийте репозиторій → **Settings** → **Pages**.

5. У блоці **Build and deployment** оберіть **Source: Deploy from a branch**, гілка **main**, папка **/ (root)** → **Save**.

6. Зачекайте 1–2 хвилини й оновіть сторінку налаштувань. Зверху з'явиться посилання на кшталт `https://USERNAME.github.io/blacksteel-barber/`. Готово.

Наступні зміни публікуються так: `git add .` → `git commit -m "…"` → `git push`. GitHub Pages оновиться сам за хвилину.

> **Open Graph.** Щоб прев'ю в Telegram/Facebook гарантовано підтягнуло картинку, після публікації замініть у `index.html` відносний шлях `assets/og-image.jpg` у тегу `og:image` на повний: `https://USERNAME.github.io/blacksteel-barber/assets/og-image.jpg`.

## Що замінити під реального клієнта

Усі контакти вигадані — перед здачею замініть їх у `index.html`:

| Що | Де шукати |
|---|---|
| Телефон `+380 67 555 17 17` | пошук по `+380675551717` і `555 17 17` |
| Telegram `blacksteel_barber` | `index.html` і константа `TELEGRAM` у `js/modules/booking.js` |
| Instagram, Viber | секція «Контакти» та футер |
| Адреса й карта | секція «Контакти» (текст і `src` у `<iframe>`) та JSON-LD у `<head>` |
| Години роботи | `HOURS` у `js/modules/booking.js` (від них залежать слоти запису й статус «Відчинено»), текст у контактах і футері, JSON-LD |
| Послуги та ціни | прайс у секції «Послуги» та `<option>` у формі запису |
| Фото «до / після» | `assets/img/ba-process-*` і `ba-result-*` — краще власні фото клієнта |
| Рядок «Концепт-сайт для портфоліо» | футер |

**Онлайн-запис.** Бекенду немає: після відправки форма показує підтвердження і кнопку переходу в Telegram з готовим текстом. Для реальних заявок форму можна підключити до Telegram-бота, Google Sheets або CRM — точка підключення в `showSuccess()` у `js/modules/booking.js`.

## Анімації й доступність

- Якщо в системі ввімкнено «Зменшити рух» (`prefers-reduced-motion`), сайт показує весь контент одразу: без прелоадера, анімацій, плавного скролу, автопрогравання і фонового відео (лише постер).
- Якщо CDN з GSAP недоступний, сайт так само працює статично.
- Кастомного курсора немає — звичайний системний.
- Усі інтерактивні елементи доступні з клавіатури: меню, лайтбокс (←/→/Esc), слайдер «до / після» (стрілки), карусель, форма.
